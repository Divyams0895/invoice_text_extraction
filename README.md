# 🧾 Invoice OCR - Invoice Details Extraction

A Python-based OCR application that extracts details from an invoice image using Tesseract OCR and displays the detected details using Streamlit.

## 📌 Project Overview

This project demonstrates how Optical Character Recognition (OCR) can be used to extract structured information from invoice images.

The application specifically identifies the **"Details"** section of an invoice and extracts the details.

## 🚀 Features

- Upload invoice images
- Extract text using Tesseract OCR
- Extract invoice details like Invoice number, Customer Name, Date, Price, etc.
- Identify the coordinates of the text
- Display the extracted details on the invoice
- Interactive Streamlit user interface

## 🛠️ Technologies Used

- Python
- OpenCV
- Tesseract OCR
- Pytesseract
- NumPy
- PIL
- Streamlit
